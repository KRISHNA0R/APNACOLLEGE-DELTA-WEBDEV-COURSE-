## 📌 About

This repository is a curated collection of practice files, assignments, and experiments built while learning full-stack web development fundamentals. It documents progressive learning — starting from basic HTML tags all the way to advanced CSS concepts like transforms, transitions, positioning, and shadows.

Every file is a small, self-contained practice or assignment that you can open directly in the browser.

## 📚 What's Inside

### 🟠 HTML — Level 1
Foundational HTML: headings, paragraphs, anchors, images, lists, and practice assignments building up to a portfolio page.

**Folder:** [`HTML/HTMLASSIGNMENTLEVL1`](HTML/HTMLASSIGNMENTLEVL1)

### 🟠 HTML — Level 2
Semantic tags, `div` vs `span`, inline vs block elements, and Emmet practice.

**Folder:** [`HTML/HTMLLVL2`](HTML/HTMLLVL2)

### 🟠 HTML — Level 3
Tables, forms, dropdowns, checkboxes, ranges, and textarea inputs.

**Folders:** [`HTMLLVL3`](HTMLLVL3) · [`HTML`](HTML)

### 🔵 CSS — Part 1 & 2
Selectors, specificity, inheritance, the cascade, and text/color styling.

**Folder:** [`cssstart/CSS PART 1 AND 2`](cssstart/CSS%20PART%201%20AND%202)

### 🔵 CSS — Part 3
The box model, `display` property, and positioning (`relative`, etc.).

**Folder:** [`cssstart/css part 3`](cssstart/css%20part%203)

### 🔵 CSS — Part 4
Visual polish: `transform`, `transition` (timing functions & delays), `box-shadow`, `background-image`, and `opacity`.

**Folder:** [`cssstart/CSS PART 4`](cssstart/CSS%20PART%204)

### 🔵 CSS — Part 5
Layouts with **Flexbox**: `display: flex`, `justify-content`, `align-items`, flex directions, and wrapping — demonstrated in a hands-on flex demo.

**Folder:** [`cssstart/css part 5`](cssstart/css%20part%205)

## 🛠️ How to Use

1. **Clone the repository**
   ```bash
   git clone https://github.com/KRISHNA0R/APNACOLLEGE-DELTA-WEBDEV-COURSE-.git
   cd APNACOLLEGE-DELTA-WEBDEV-COURSE-
   ```

2. **Open any file**
   - Double-click an `.html` file, **or**
   - Use the **Live Server** extension in VS Code for hot reload.

3. **Explore & Tweak**
   - Edit the linked `.css` files to experiment with styles.
   - Refresh the browser to see changes instantly.

> 💡 Tip: Most HTML files reference a sibling `.css` file in the same folder.
